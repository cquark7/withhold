## Before upgrading

Run `withhold off` with the installed binary before replacing it, then install
v0.1.4 and start a new session. Copilot embeddings requests that withhold cannot
inspect are now blocked instead of forwarded unscanned.

## What's new

- Secret detection now uses Betterleaks v2.0.0-rc.9, adding rules such as
  Anthropic OAuth tokens, Cal.com, and Jina AI. Long values are scanned intact,
  nested JSON keeps its credential context, and supported whole-value Base64 is
  decoded, scanned, and rewritten.
- Copilot embeddings follow the shared fail-closed policy: detected secrets are
  redacted, and inspection failures or unsupported bodies are blocked instead
  of passing through unscanned.
- Applying proxy settings preserves comments and formatting on unrelated editor
  settings. `withhold off` removes only the Settings Sync exclusions that
  withhold added.
- The placeholder key file must be private (mode `0600` or a protected
  current-user ACL). If it is not, withhold uses a process-random key for that
  session, so placeholders are not stable across runs.
- `withhold off` clears an exited session even when another process now uses its
  port, instead of retaining the recovery record and reporting a held port.
